# クリエイティブ・イノベーション・ラボ（creative_org）

実用性よりも、創造性と革新性を最優先にするブレインストーミング向けの組織です。

**理念**: 常識を打ち破る革新的なアイデアで世界を変え、人々の想像力と可能性を無限に拡げる

**行動指針**: 創造性 / 挑戦性 / 多様性 / 実験性 / 情熱性

## メンバーと役割

| 人材 | 役割（スロット） | 内容 |
|---|---|---|
| るい（`rui`） | ワイルドアイデア（`wild_idea`） | 「もしも〜だったら？」と、常識の枠を楽しく壊す発想者 |
| そら（`sora`） | ビジョナリー（`visionary`） | 10〜20 年先の未来から現在を見る |
| くろ（`kuro`） | 悪魔の代弁者（`devils_advocate`） | 健全な懐疑心で前提や盲点を突き、改善案を添える |
| ななみ（`nanami`） | 創造性重視（`creative`） | 異分野の知恵を組み合わせて新しい価値を作る |
| みお（`mio`） | モデレーター（`moderator`） | 議論を整理して要約する前向きな進行役 |

4 つのワークフローはすべて、この 5 人を同じスロットに割り当てています。

## ワークフロー

| ワークフロー | 内容 |
|---|---|
| `creative_brainstorm`（既定） | 制約のない自由な発想から、革新的なアイデアを生み出す |
| `innovation_challenge` | 業界の常識を覆す革新的ソリューションを創る |
| `wild_ideas` | 常識破りの奇抜なアイデアから、天才的な発想を見つける |
| `future_scenario` | 理想的な未来像から逆算した革新的な戦略を組み立てる |

## 使い方

```bash
python MultiRoleStudio.py --org creative_org --workflow creative_brainstorm --topic "あなたのトピック"
python MultiRoleStudio.py --org creative_org --workflow innovation_challenge --topic "業界課題"
python MultiRoleStudio.py --org creative_org --workflow wild_ideas --topic "自由なテーマ"
python MultiRoleStudio.py --org creative_org --workflow future_scenario --topic "未来構想"
```
